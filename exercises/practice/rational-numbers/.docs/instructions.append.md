# Instructions.append

Students who enjoy a tougher challenge can enable the bonus tests, by uncommenting a line in `rational-numbers.jl`.

These require a significantly more advanced knowledge of Julia and its type system.

The `runtests.jl` file contains a few links which may be helpful.

The `rational-numbers.jl` file deliberately contains no further guidance for the bonus tests: think carefully about imports, type definitions and extra functions.
