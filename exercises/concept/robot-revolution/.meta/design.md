# Design

## Goal

The goal of this exercise is to teach the student how to basic linear algebra functionality in Julia.

## Learning objectives

- Understand that Julia has built in basic linear algebra functionality and extended functionality by calling the `LinearAlgebra` library.
- Understand how to change a vector of vectors into a matrix.
- Understand how to perform matrix multiplication.
- Understand elementwise operations.
- Understand the uses of a dot product.
  
## Out of scope

- Transpose
- Cross product

## Concepts

- `linear-algebra-basics`

## Prerequisites

- `multi-dimensional-arrays`
